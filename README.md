# Age Calculator

This is one of my first Python projects while learning programming.

The program asks for your birth date and calculates your exact age. It shows your age in years, months, and days, and also tells you how many days you have been alive.

## Features

- Calculates your exact age
- Shows years, months, and days
- Calculates total days you have been alive
- Takes user input from the terminal
- Handles invalid inputs using try and except
- Works with different month lengths and leap years
